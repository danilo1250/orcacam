# OrçaCam

Aplicativo web para montar orçamentos de câmeras de segurança e gerar o PDF para enviar ao cliente.

- Cadastro de produtos e serviços, com importação do nome pelo link do anúncio
- Orçamento com quantidades, preços ajustáveis e desconto
- PDF em A4 com os dados e a logo da empresa
- Funciona no celular, pode ser instalado na tela inicial e abre sem internet

Os dados ficam guardados só no navegador de quem usa. Use "Salvar backup" na aba "Minha empresa" para não perder nada ou para levar os dados a outro aparelho.

Não precisa de servidor nem de instalação: basta hospedar estes arquivos (por exemplo, no GitHub Pages).
